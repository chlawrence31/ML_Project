## ML Fruit Classification Project
This repository contains several machine learning models for Jupyter Notebooks classifying fruits of different varieties including KNN, ANN, Logistic Regressions and ANNs (artificial Neural Networks).The dataset used for this activity was the fruits 360 dataset. Each Notebook can be executed following to the preprocessing steps below and resulting matches are tested and plotted. 

## Preprocessing Usage: 
Please create the following directory: ML_FINAL_PROJECT and store the fruits360 dataset in there, make sure the training and test subfolders are available in the directory. 
If you are using anything other than Neural Networks, please use the getSamplesMat() function that is demoed in the file. Create a separate notebook for each test.
